# VWS テロップファイル (.ts1) 構造メモ（非公式・解析中）

サンプル 1 件（単一行・16 文字）をもとにリバースエンジニアリングした結果です。
「確認済」は解析→再構築のバイト一致やレイアウト計算で裏付けが取れたもの、
「推定」は実機での確認がまだのものです。

## 共通ルール（確認済）

| 項目 | 内容 |
|---|---|
| エンディアン | リトルエンディアン |
| チャンク | 4 文字タグ + `u32` サイズ（ヘッダ 8 バイトを含む）+ ペイロード |
| 例外 | `WVCT` のサイズはヘッダ 8 バイトを含まない。`ESET` は `"ESET" + u32 0 + u16 件数` の 10 バイト固定。`EMTR` は `"EMTR" + u32 文字コード + 12 バイト 0` の 20 バイト固定 |
| 数値 | 座標・サイズの多くは **24.8 固定小数点**（`i32 / 256`） |
| 文字列 | `u8 長さ`（0 のときは続く `u16` が長さ）+ `FF FE` + UTF-16LE + `00 00` |

## MCHR（1 文字）（確認済）

```
"MCHR" u32 size | u16 1 | u16 グリフ番号(ORMP 内の RCHR の添字) | 22B (0)
[ DAAR: u16 1, u16 子数, 属性チャンク… ]   ← 書式変更がある文字だけ
"EMTR" u32 文字コード 12B(0)
```

属性チャンク（先頭文字が全部持つ。以降は変更点のみ）

| タグ | 値 | 意味 |
|---|---|---|
| ADCO | 104B | 装飾（文字面・縁）。+8 / +58 に色リソース番号（16,17）、+88 / +92 に縁幅らしき値 (6)（推定） |
| AFIN | 0 | ? |
| ACTP | u32 0x45F | フォント番号（VWS 内部） |
| ACSZ | 24.8 ×2 | 文字サイズ 幅・高さ (100, 100) |
| AFLF | 4 | ? |
| ASLP | 0 | 斜体角? |
| AROT | 0 | 回転? |
| ALSP | 24.8 | 行間 (10) |
| ACMG | 24.8 ×2 | 倍率 (100%, 100%)? |
| ACSP | 24.8 | 字間 px（-3, -6 など） |

## RCHR / WVCT（グリフ）（確認済）

Windows GDI `GetGlyphOutline(GGO_NATIVE)` とほぼ同じ形式で、セル高 2048（ascent 1802 + descent 246）。
座標は整数、y は下向き（ベースライン = 0）。

```
"RCHR" u32 size | u16 1 | u16 使用回数 | u16 0 | u32 フォント番号 | u32 0 | u32 文字コード
"WVCT" u32 (size-8) | u32 輪郭データ長 | 60B ヘッダ | 輪郭…
  ヘッダ: u16 輪郭数, u16 1, bbox(l,t,r,b) 24.8 ×4, u16 2048, u16 2048, u16 黒枠幅, u16 黒枠高,
          u32 フォント番号, u32 文字コード, i32 ascent, i32 -descent, ABC幅 (A,B,C), u32 0
  輪郭:   u32 1, u32 以降のバイト数, i32 x, i32 y (始点)
          { u16 種別(1=直線, 2=2次スプライン), u16 点数, (i32 x, i32 y)×点数 } …
```

## レイアウト（推定・OFRI と ±1px で一致）

- 文字送り = 文字サイズ（全角セル）+ ACSP
- 行は CSML.x から幅 CSTR.width の枠で **中央揃え**
- CSML.y がベースライン
- 縁は約 6〜7px

## 未確認（実機での確認が必要）

1. CRGB のバイト順（縁の色が赤橙 #E72F12 なのか青 #122FE7 なのか）
2. 改行の表現（2 行テロップのサンプルが必要）
3. 半角文字の送り幅（半角を含むサンプルが必要）
4. ADCO 内の縁幅・色参照の正確な位置
5. フォント番号 0x45F と実フォント名の対応
6. 文字単位の ACSP が「その文字だけ」か「以降継続」か（生成時はどちらでも同じ結果になるよう出力）
