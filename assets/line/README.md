# LINE公式アカウント用ビジュアル

「尾藤AI 校閲＆文字起こしサービス」のプロフィール画像・背景画像一式。

## 書き出し済みアセット

| ファイル | サイズ | 用途 |
| --- | --- | --- |
| `icon-640.png` | 640 × 640 | プロフィール画像（メイン案：吹き出し＋波形＋赤の校閲チェック） |
| `icon-640-monogram.png` | 640 × 640 | プロフィール画像（別案：「尾藤」ロゴタイプ） |
| `icon-640-wave.png` | 640 × 640 | プロフィール画像（別案：波形バッジ） |
| `bg-1080x878.png` | 1080 × 878 | 背景画像（メイン案：ネイビー） |
| `bg-1080x878-light.png` | 1080 × 878 | 背景画像（別案：ライト） |

LINE公式アカウントの推奨値（プロフィール画像 640×640・3MB以下 JPG/PNG、背景画像 1080×878・10MB以下）に合わせています。
プロフィール画像は円形に切り抜かれて表示されるため、要素はすべて中央の円内に収めています。
背景画像は下部にプロフィール画像とアカウント名が重なるため、下 1/3 には文字を置かず、装飾の波形のみにしています。

## デザインの考え方

- **紺〜青のグラデーション**：AI・テクノロジーらしさと、文書仕事の信頼感。
- **音声波形 → テキスト行**：文字起こし（話し言葉が原稿になる）をひと目で伝えるモチーフ。
- **赤（コーラル）のチェック／下線**：赤入れ＝校閲・校正の記号。アクセントは1色だけに絞る。
- 小さく表示されても崩れないよう、要素は「吹き出し」「波形」「チェック」の3つに限定。

## 再生成

```bash
pip install pillow fonttools brotli numpy
cd assets/line/tools
python3 icon.py   # プロフィール画像
python3 bg.py     # 背景画像
```

初回実行時に Google Fonts から Noto Sans JP のサブセットを取得して `tools/fontcache/` に置きます（gitignore 済み）。
キャッチコピーやピルの文言は `bg.py` 冒頭の定数（`TITLE_A` / `TITLE_B` / `LEAD` / `PILLS`）を書き換えれば差し替えられます。
新しい漢字を使う場合は `gfx.py` の `NEEDED` にも追加してください（未収録の文字は実行時に警告が出ます）。
